# GTA VI Trophy Guide — make.fun entry

The complete Grand Theft Auto VI trophy guide: all 55 PS5 trophies (1 Platinum, 2 Gold, 6 Silver, 46 Bronze) with official descriptions, grades, how-to-unlock tips, and a progress tracker that saves offline. About 200 hours to Platinum (difficulty 4/10). Works fully offline.

The guide opens with a Platinum roadmap — one playthrough is enough, but there is no mission replay, so it flags the one potentially missable trophy (Positive Mental Attitude) up front and walks through the story, 100% completion, and cleanup phases. A live Next Up list always shows the five most useful trophies to chase next, and every trophy can be searched, filtered by grade, category and earned status, sorted, and checked off; checkmarks are stored in the browser's local storage. A spoiler toggle blurs story trophy names and descriptions, and the progress card tracks Gamerscore (1,000 total), per-grade counts, and per-category bars.

## Run

Serve with `node serve.ts`, then open http://localhost:8080. No build step, no server beyond that, no network needed. Click a trophy to mark it earned; progress is saved in your browser.
